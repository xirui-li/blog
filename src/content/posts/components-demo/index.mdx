## Interactive components

Any `.astro` component with a `<script>` works; the script is bundled and loaded once per page. Post-specific components live next to the post's `index.mdx`.

<Figure caption="Counter.astro — two instances, each with independent state.">
  <Counter />
  <Counter start={10} />
</Figure>

To use a UI framework (React, Svelte, …) instead, add its integration with `npx astro add react` and hydrate the component with a directive such as `client:visible`.

## Diagrams

`<Diagram>` draws box-and-arrow figures in the style of Meta research papers. Place nodes by coordinates (viewBox units); edges route themselves with rounded corners. Wrap it in `<Figure title="…">` for a numbered, paper-style caption.

Node `kind` sets the color: `model` (teal), `engine` (yellow), `source` (purple), `decoder` (blue), `mesh` (green), `splat` (peach), `neutral`, `tag` (peach pill), `dark`, `go`, `gray`, `plain`. Node `shape`: `box`, `pill`, `trapezoid`, `tokens`, `image`, `text`.
