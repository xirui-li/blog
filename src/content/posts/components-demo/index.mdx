## Video

Paths are relative to `public/`. Absolute URLs work too, for clips hosted outside the repo.

```mdx
<Video src="videos/components-demo/test-pattern.mp4"
       poster="videos/components-demo/test-pattern.jpg"
       caption="A standard player." />
```

## Interactive components

Any `.astro` component with a `<script>` works; the script is bundled and loaded once per page. Post-specific components live next to the post's `index.mdx`.

<Figure caption="Counter.astro — two instances, each with independent state.">
  <Counter />
  <Counter start={10} />
</Figure>

To use a UI framework (React, Svelte, …) instead, add its integration with `npx astro add react` and hydrate the component with a directive such as `client:visible`.

## Figures and images

```mdx
<Figure caption="Caption text.">
  ![alt text](./diagram.png)
</Figure>
```

Images placed next to the post and referenced with a relative path are optimized at build time.
