Welcome! This blog is built with [Astro](https://astro.build) and MDX, and deployed to GitHub Pages.

## What to expect

Notes on research, engineering, and things I am learning along the way.

## How posts are written

Each post is a folder under `src/content/posts/` with an `index.mdx` file. Posts can mix Markdown with components such as videos, figures, and interactive widgets.
